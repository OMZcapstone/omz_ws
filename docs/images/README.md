## 권장 사항

- 사진은 긴 변 1600 px 내외로 리사이즈해 커밋하세요 (원본 4032 px는 저장소를 불필요하게 키웁니다).
- 표정 캡처는 PNG, 실물 사진은 JPG를 사용합니다.
- 인물·차량 번호판이 찍힌 사진은 공개 전 마스킹하세요.
